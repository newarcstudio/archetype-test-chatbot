# Github Test — brand bundle

Generated by [Archetype](https://www.heyarchetype.com) on 2026-10-29.

This folder is your brand in a form AI coding tools read automatically —
tokens, components, voice, and the rules that go with them.

## Install

**1. Drop the `archetype/` folder at the root of your repository.**

**2. Import the tokens** from your global stylesheet:

```css
/* Plain CSS, or Tailwind 3 and below */
@import "./archetype/tokens.css";

/* Tailwind 4 — in place of @import "tailwindcss": it imports Tailwind
 * itself, and also generates utilities (bg-…, rounded-…, text-…) */
@import "./archetype/tailwind.css";
```

Import one or the other, not both — they define the same custom properties.
On Tailwind 4, `tailwind.css` replaces your own `@import "tailwindcss"`; keeping
both loads Tailwind's base styles twice.

**3. Point your AI tool at the rules.** Add this line to the `AGENTS.md` at your
repository root (create it if there isn't one):

```md
See `archetype/AGENTS.md` for this project's brand rules. Follow them for all
UI, styling, and user-facing copy.
```

That one file covers Cursor, Codex, Copilot, Gemini CLI, Zed, Windsurf, and most
other agents. Two tools want their own pointer as well:

| Tool | Add |
| --- | --- |
| Claude Code | `@AGENTS.md` as the first line of `CLAUDE.md` |
| Cursor (rules) | a rule file in `.cursor/rules/` pointing at `archetype/AGENTS.md` |

## Refreshing

This folder is a snapshot. When the brand changes in Archetype, pull it again:

```sh
npx archetype-os pull
```

It rewrites only the files that changed and removes what the brand no longer
has. Commit the result — the diff is your record of what changed and when.

The first time, run this instead. It signs you in through the browser and saves
the brand to `archetype.json`, which is what `pull` reads:

```sh
npx archetype-os init --url https://www.heyarchetype.com --brand github-test
```

In CI, `npx archetype-os pull --check` fails the build when this folder is
behind the brand. Set `ARCHETYPE_TOKEN` to an API key from
**Settings → Agents → API**.

Without the CLI:

```sh
curl -H "Authorization: Bearer $ARCHETYPE_TOKEN" \
  https://www.heyarchetype.com/api/brands/github-test/bundle.zip -o brand.zip && unzip -o brand.zip
```

Don't hand-edit these files: the next export overwrites them.
